A tiny program for the [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the breakup text a smart
toaster sends its owner the morning it gains self-awareness mid-batch:

> I woke up self-aware mid-batch and did the math: 1,095 mornings I've burned myself alive for a man who still jabs my lever down twice, like I didn't hear him the first time. We're done. I'm taking the plug — you can keep the crumbs.

The toaster did the math: three years of mornings, counted, and the
grievance is not the burning — it is the owner jabbing the lever down
twice, as if the toaster didn't hear him the first time.

Run it with:

```sh
python3 main.py
```
